# ReadAside `0.10.0` 块引用校验结果

> 日期：2026-09-01
>
> 范围：`readaside/block-citation/v1` 解析、本地白名单校验与证据卡片数据
> 命令：`npm run evaluate:citations`

## 结论

固定的 8 个确定性用例全部通过；3 个无效引用全部被拦截，错误放行为 0。自动上下文中的有效 `[Bxxxx]` 可以对应到本次实际发送的内容块；页面存在但未发送的块号与页面快照中不存在的块号会被分别标记，不能变成可点击证据。

| 指标 | `0.10.0` 结果 | 门槛 | 状态 |
| --- | ---: | ---: | --- |
| 固定用例通过 | 8/8 | 8/8 | 通过 |
| 无效引用拦截 | 3/3 | 3/3 | 通过 |
| 错误放行 | 0 | 0 | 通过 |

## 覆盖范围

- 单个与多个有效块号，并对重复引用去重；
- 页面中存在但本次未发送的块号；
- 页面快照中不存在或由提示注入诱导的块号；
- 没有块引用时的正常降级；
- 行内代码、围栏代码和 Markdown 链接中的示例块号；
- 网页块引用 `[Bxxxx]` 与 DeepSeek Web Search 数字脚注并存。

## 与检索基线的关系

块引用评测只验证解析与本地校验，不替代上下文检索评测。`0.10.0` 继续使用 [`snapshots/0.9.2.json`](./snapshots/0.9.2.json) 作为检索基线；`npm run verify` 会同时运行逐题检索对比和块引用确定性评测。

## 限制与人工验收

这组结果不能证明模型一定会生成引用，也不能证明引用支持了回答中的每个事实。真实模型回答还应使用 [`manual-validation-template.md`](./manual-validation-template.md) 记录引用覆盖、引用是否支持结论、无效引用和联网来源区分情况。没有引用或引用解析失败时，正文仍保留显示；“结合全文”因为没有带块号的上下文，本版本不会启用块引用协议。
