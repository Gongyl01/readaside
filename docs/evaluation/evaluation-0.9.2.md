# ReadAside `0.9.2` 上下文评测结果

> 日期：2026-09-01
>
> 阶段：M0-B 30 题收口
> 性质：离线、确定性评测，不调用 DeepSeek

## 结论

固定 30 题评测的证据召回为 **100%（32/32）**，上下文缩减中位数为 **76%**，高于路线图设定的 **60%** 门槛；三个夹具各自的召回和缩减门槛也全部通过。与调整前 `0.9.1` 快照相比，证据召回保持不变，缩减中位数从 46% 提升到 76%。

这组结果证明当前确定性夹具上的块级检索满足既定门槛，不等同于模型回答准确率，也不能替代真实网页人工验收。

## 范围与方法

- HTML 夹具：[technical-doc.html](../../test/fixtures/context/technical-doc.html)、[long-article.html](../../test/fixtures/context/long-article.html)、[complex-dom.html](../../test/fixtures/context/complex-dom.html)。
- 等价结构化夹具位于 [`test/fixtures/context`](../../test/fixtures/context/)。
- 30 个问题及证据标注位于 [`test/evaluation`](../../test/evaluation/)。
- 评测命令：`npm run evaluate:context`。
- 强制门槛：`npm run evaluate:context:gate`。
- 每条证据必须且只能命中一个内容块；歧义、缺失或重复问题编号会直接让评测失败。
- `Recall@K` 按选中的必需证据块数除以全部必需证据块数计算。
- 上下文缩减按 `1 - 自动上下文字符数 ÷ 完整兼容文本字符数` 计算。

复杂 DOM 夹具明确保留主页面、iframe 和开放式 Shadow DOM 的来源元数据，用于验证邻近扩展不会跨文档层串联。全部内容均为虚构测试数据，不调用网络和模型。

| 上下文缩减中位数 | 46% | 76% | ≥ 60% | 通过 |
| 自动全文回退 | 0/30 | 0/30 | 仅安全回退 | 正常 |

性能数字来自本机 30 次重复运行，会随机器负载波动；门槛检查使用实际运行值，不把报告中的近似值当作固定常量。

## 检索调整

本轮只修改通用规则：

1. 词法种子最多从 4 个收敛到 2 个。
2. 复合问题按分句分别选择词法种子，避免两个名额都被同一半问题占用。
3. 每个种子继续保留所属标题，但只补一个同来源层、同标题路径的正文邻块。
4. 选区固定、16,000 字符预算、2,000 字符短页全文、概览采样和“结合全文”回退语义不变。

调整没有加入网站名单、向量服务、远程索引或模型调用。

## 限制与下一步

- 30 题仍是小型确定性集合，主要测量证据是否被发送以及发送量，不评估回答是否完整、是否正确引用或是否能回到原文。
- 复杂 DOM 使用稳定本地夹具，尚未覆盖浏览器权限变化、动态重排和跨域不可读 iframe。
- 后续进入 M3 时，应继续使用同一评测集保护检索结果，并新增块引用解析、合法性校验和提示词注入测试。
